Security Features Demonstrated

🔒

HTTPS / TLS

All traffic encrypted using TLS. HTTP on port 5001 auto-redirects to HTTPS on port 5000.

🛡️

CSRF Protection

Every state-changing form is guarded by a time-limited CSRF token via Flask-WTF.

🔑

Password Hashing

Werkzeug PBKDF2/Scrypt hashing. Plaintext passwords are never stored in the database.

🍪

Secure Sessions

HttpOnly, Secure, SameSite=Lax session cookies prevent XSS theft and CSRF attacks.

📋

Security Headers

CSP, HSTS, X-Frame-Options, X-Content-Type-Options, and Referrer-Policy on every response.

🗄️

Safe Queries

SQLite parameterized queries on all database operations — SQL injection prevented by design.

Technology Stack

BackendPython 3 + Flask
DatabaseSQLite 3
AuthWerkzeug + Flask Sessions
CSRFFlask-WTF
TLSPython ssl module
FrontendHTML5 + CSS3 + Vanilla JS
